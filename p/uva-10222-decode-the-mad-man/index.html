UVA 10222 - Decode the Mad Man

Jul 16, 2025
閱讀時間: 1 分鐘

題目連結 : 10222 - Decode the Mad man

解題思路

  • 建立鍵盤
  • charAt() 把字串逐一排查
  • indexOf() 找出字元在鍵盤的位置，因為題目是左移兩格，所以必須-2才可順利解碼
  • charAt() —> 知道「位置」，想找尋 「字元」
  • indexOf() —> 知道「字元」，想找尋 「位置」，傳回 -1 表示找不到

參考解答(JAVA) 

import java.util.Scanner;

public class main{
	public static void main(String args[]){
		Scanner sc = new Scanner(System.in);
		String keyboard = "qwertyuiop[]\\asdfghjkl;'zxcvbnm,./";
		
		while(sc.hasNextLine()){
			String text = sc.nextLine().toLowerCase();
			
			for(int i = 0; i < text.length(); i++){
				// 取當前字元
				char word = text.charAt(i);
				// 找出鍵盤對應位置
				int letter = keyboard.indexOf(word);
				// 如果index不等於-1代表此字元存在鍵盤中
				if(letter != -1 && letter >= 2){
					System.out.print(keyboard.charAt(letter - 2));
				}else{
					System.out.print(word);
				}
			}
			System.out.println();
		}
	}
}
